Analytical design decisions, recorded before creating the schematic, 7 October 2026.

Use six owned NEC/Renesas uPC4570G2 dual op-amps at externally regulated +/-15 V. User confirms exact marking and selects 2012 metric resistors. Manufacturer pin numbering and 4.4 x 5.2 mm SOP body / 1.27 mm pitch are authoritative; a standard narrow SOIC footprint is unsuitable.

Select sources before input buffers with two DPDT relays: one selects both signal conductors, the other both RCA returns. Reference returns join only while selected. LFE drives both buffered inputs in AV mode so the averaging summer remains unity gain. No resistor, capacitor, shield connection or protection device may bridge an inactive source to board ground.

Use active averaging -(L+R)/2 followed by a unity inverter, not gain-two summing. Input resistance 47k per channel, deliberately within the 4570 recommended source-resistance limit. Existing main speakers remain full range.

Two unity Sallen-Key low-pass stages with equal selectable resistors, 200n feedback capacitance (2 x owned 100n in parallel) and 100n grounded capacitance give Q=0.7071. Fixed resistor selections are 28k, 22k6, 18k7, 16k2, 14k, 11k3, 9k31. One section is 12 dB/octave Butterworth; two are an electrical LR4 response at 24 dB/octave. No complementary main-speaker filter exists, so no acoustic LR summation is assumed. MFB would invert and couple tuning ratios; state-variable uses more op-amps for little advantage at fixed Q. Four independent jumper banks implement precision resistor switching; all four must match. Panel selector implementation remains a layout approval choice.

Use one inventory CS3310 for mono attenuation with two independently stored mode settings, not as a rheostat. Fixed gain -0.5 before and -2 after it preserves overall unity gain while providing 4 Vrms design source capacity. CS3310 analog +/-5 V and its digital VDD tied to its positive analog supply. MCU/relay control has a separate +5 V regulator. Discrete collector interfaces prevent separate-rail digital back-power. CS register is restricted to attenuation (0 to -95.5 dB) and mute. No ADC, DAC or DSP is in the audio path.

LM1971 is a 4.5-12 V single-supply ladder attenuator, 1 dB steps, needing very low input-bias output buffering; split supplies need logic level shifts. That conflicts with the preferred ordinary 4570 building block and adds coupling/reference circuitry. NJW1195A has four volume channels and input selection, +/-3.5 to +/-7.5 V supplies, 0.5 dB steps, and many reference/noise suppression capacitors. It is useful but excessive for this mono task. Owned PGA2311 DIP is another viable +/-5 V level controller but loses the SMD preference. No suitable true digital rheostat was found using function searches and category browsing. None of these devices changes frequency or phase resistance.

One unity all-pass has H=(1-sRC)/(1+sRC), C=220n, R=2k2+(50k pot in parallel with 470k). It is bypassable and complemented by a unity inverter / 0-180 polarity selector. It is frequency-dependent phase, not time delay. Default all-pass bypass prevents an accidental AV phase adjustment.

Unity Sallen-Key Butterworth HP uses C1=C2=440n (each 2 x owned 220n), R2 about 2R1. Select 15/20/25 Hz or bypass. Reference default 20 Hz. A spare mode-relay pole allows independently configured AV HP bypass or shared HP. Default AV bypass preserves the AVR bass-management response; select protection only after checking system needs.

Four owned G6K-2P-Y 5 V relays cover signal selection, return selection, LP/AV-HP selection and output mute. Output relay defaults to grounded amplifier input and disconnects the buffer. ATtiny412 keeps PA0 for UPDI; an owned MCP23008 adds encoder, trigger, status and relay IO. No unnecessary amplification, driver-specific bass boost or enclosure equalisation.

Rail monitoring independently clamps RUN low on analog supply loss; firmware sequences mute before mode changes and holds startup mute until supplies/filter DC settle. New optocoupler input is specified for an isolated 12 V trigger, with selectable series resistance for 5 V. External PSU early power-fail input is included because relay release time cannot guarantee silence during arbitrarily fast rail collapse. Power-up/down and firmware remain bench qualification gates.

Ground is one board GND with analog/control placement regions, local returns and no arbitrary plane split. Insulated RCA shells and panel hardware are required. Board supply/amp signal returns meet at the amplifier small-signal star; no speaker/rectifier current through this PCB. Protective earth is permanently bonded to chassis outside this SELV PCB and is never switched. Any chassis loop breaker belongs at the single system audio-star-to-chassis bond, only after the existing amplifier grounding is verified.

Noise/headroom estimates, response curves and tolerance calculations are generated by tools/analyse.py. They are ideal circuit analysis, not measured performance or manufacturer-model SPICE simulation. Conservative target is below 15 uVrms output over 20 Hz-20 kHz, dominated by the CS3310 and output gain; bench measurement is required.
