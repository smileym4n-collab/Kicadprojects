# ClassA2 — Hiraga-inspired Class-A amplifier (Rev A, schematic for review)

This is one mono channel of a discrete Class-A amplifier: build two boards for stereo. It keeps the basic shape of Jean Hiraga's *Le Monstre*: complementary push-pull from input to output, one complementary-feedback-pair output stage at about 0.7 A, low rails and moderate global feedback. The bias is set by a heatsink-mounted VBE multiplier, and every stage uses transistors from your inventory.

**Status:**
- **Schematic:** KiCad ERC 0 errors / 0 warnings, netlist cross-checked against the SPICE deck. Not released for PCB.
- **Simulation:** done, with author-approximate models.
- **Bench tests:** none yet.
- **PCB:** the file is the original empty one, untouched.

| Target | Result (simulation, nominal rails) |
|---|---|
| Output | Class A to 7.5 W / 8 Ω; 12 W at 1 % THD (10.3 W at low mains) |
| Supply | external ±V; 12-0-12 VAC 100 VA gives ±15.6 V loaded (14.1–17.6 V over mains range) |
| Bias | 0.70 A per channel (231 mV across each 0R33), adjustable 0.075–0.94 A, fail-safe trimmer |
| Gain / input impedance | 24.4 dB / ≈ 46 kΩ |
| Response | −0.03 dB at 20 Hz, −0.07 dB at 20 kHz |
| Offset | −15 mV untrimmed; RV2 trims about +17 to −47 mV |
| Stability | 82–95° phase margin, ≥ 23 dB gain margin, open load to 10 µF (with L1) |
| THD (model estimate) | 0.0015 % at 1 W, 0.006 % at 7.5 W, 1 kHz |
| Idle dissipation | 22 W per channel; heatsink ≤ 1.1 K/W per channel |
