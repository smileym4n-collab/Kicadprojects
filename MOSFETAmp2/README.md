# MOSFETAmp2 — stereo discrete Class-AB prototype

**Rev 0.2: electrically connected development schematic, not released for PCB fabrication.** KiCad ERC and the independent connectivity checks pass. Rev 0.2 replaces the Rev 0.1 Zener bias spreader, which failed a low-threshold/hot model corner, with a fixed-ratio heatsink sensor plus a programmed, low-temperature-coefficient offset. In simulation its temperature compensation no longer depends on device threshold. The real MOSFET VGS slope, select-on-test values, hot linear-mode SOA and measured audio performance remain unverified. The original empty PCB is preserved for the user's layout.

Each channel uses a BC556 differential pair, BC546 mirror/buffer, BD139 VAS, active current-source load, thermally sensed bias spreader with programmed offset, BD139/BD140 drivers and one **IRF540N/IRF9540N** source-follower pair. One global DC-coupled feedback loop gives approximately **20.44 dB** gain from a **23 kΩ** input. Local decoupling, source resistors/test loops, gate stoppers/clamps, Zobel and a damped output coil are included. There is **no output short-circuit protection**, as requested. Use the separate speaker-protection board after its operation is verified.

Simulated output into 8 Ω (Infineon MOSFET models, stiff rails) is about **2.1 W at ±12 V, 4.6 W at ±15 V and 5.7 W at ±16 V** before significant clipping. These are development estimates, not hardware ratings. Gate-drive headroom limits power. The assumed 12-0-12 VAC/4,700 µF PSU gives a conditional envelope of roughly 12.5 V loaded valley to 20.6 V high-mains/no-load peak per rail. No transformer/capacitor is fixed yet. **4 Ω operation is not qualified.**

Start by reading the bias sections and the bench procedure. **Characterize the MOSFETs first, then select R113/R213 from the measured VGS slope. Fit the J101/J201 bias-short links for first power-up, leave R114/R214 unfitted, and set both trimmers to maximum measured resistance.** A simulated trimmer setting must never be copied to the build. Each channel needs individual adjustment with a meter across its 0R33 source resistors; 16.5 mV corresponds to 50 mA. The thermal match depends on R113 matching the real devices, and the sensor's lag behind the die and the rail sensitivity remain; warm-up behaviour must be measured.
