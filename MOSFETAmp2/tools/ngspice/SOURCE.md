# Bundled ngspice 47

Built locally from the unmodified official ngspice 47 source for macOS arm64. This is a command-line simulator runtime, not an amplifier model. Licensing is in COPYING.

Source: https://sourceforge.net/projects/ngspice/files/ng-spice-rework/47/ngspice-47.tar.gz/download

Downloaded source archive SHA256: `894e649651f1838a14095e5a5439e7d3aa63e87ede14d283173fda4fcdef675f`.

To use another installation, set the environment variable NGSPICE to its executable path. No global Homebrew packages or user-wide application settings were changed. The local install's initialization paths were generated for this workspace; its required native SPICE models do not depend on external OSDI files.
